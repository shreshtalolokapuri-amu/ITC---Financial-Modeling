# ITC Financial Modeling
Financial Modeling project of ITC dataset from Scaler

**Project Overview**  
This project focuses on performing a comprehensive financial analysis of ITC Limited using historical financial data. The analysis was conducted to understand the company’s financial performance, profitability, liquidity, efficiency, and overall business health through various financial modelling techniques.  
**Objectives**  
Analyze historical financial statements of ITC Limited  
Prepare common size financial statements  
Perform ratio analysis for business evaluation  
Summarize findings in a concise one-page financial report  
**Tools & Skills Used**  
Microsoft Excel  
Financial Modelling  
Financial Statement Analysis  
Ratio Analysis  
Business Analysis  
Data Interpretation  
**Data Source**  
The financial data used in this project was sourced from the financial modelling resources and datasets provided by Scaler  
**Project Components**  
**1. Historical Financial Statements**  
Prepared and analyzed:  
Income Statement  
Balance Sheet  
Cash Flow Statement  
The historical data was used to identify financial trends and evaluate company performance over multiple years.  
**2. Common Size Statements**  
Converted financial statements into percentage-based common size statements to:  
Compare yearly performance  
Understand cost and revenue structure  
Analyze asset and liability composition  
**3. Ratio Analysis**  
Performed key financial ratio analysis including:    
1. Growth Ratios  
These ratios measure the company’s growth performance over time.  
Sales Growth  
EBITDA Growth  
EBT Growth  
Dividend Growth  
Net Profit Growth  
2. Profitability Ratios  
These ratios evaluate the company’s ability to generate profits from revenue and operations.  
Gross Profit Margin  
EBITDA Margin  
EBIT Margin  
EBT Margin   
Net Profit Margin  
3. Operating Efficiency Ratios  
These ratios measure operational cost efficiency and asset utilization.  
Sales Expenses % Sales  
Depreciation % Sales  
Fixed Asset Turnover Ratio  
Capital Turnover Ratio  
4. Return Ratios  
These ratios measure returns generated for investors and capital providers.  
Return on Capital Employed (ROCE)  
Return on Equity (ROE)  
Retained Earnings %  
Self Sustained Growth Rate  
5. Solvency Ratios  
These ratios evaluate long-term financial stability and debt servicing capability.  
Interest Coverage Ratio  
6. Working Capital Management Ratios  
These ratios measure efficiency in managing receivables, payables, and inventory.  
**Turnover Ratios**  
Debitor Turnover Ratio  
Creditor Turnover Ratio  
Inventory Turnover Ratio  
**Working Capital Cycle Ratios**  
Debtor Days  
Creditor Days  
Inventory Days  
Cash Conversion Cycle (in days)  
7. Cash Flow Ratios  
These ratios evaluate cash generation efficiency and liquidity strength.  
CFO / Sales  
CFO / Total Assets  
CFO / Total Debt  
**4. One Page Financial Report**
Created a concise one-page report summarizing:  
Financial insights  
Key performance indicators  
Business strengths and weaknesses  
Overall financial position of ITC Limited  
**Key Learnings**  
Understanding financial statement structures  
Interpreting company financial performance  
Applying ratio analysis techniques  
Building financial analysis reports  
Improving analytical and business decision-making skills  
**Conclusion**  
This project helped develop practical knowledge in financial modelling and business analytics by applying financial analysis techniques to a real-world company dataset.
